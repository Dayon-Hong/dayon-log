## 먼저 생각할 것

조회 성능과 쓰기 비용 사이에서 인덱스를 선택하는 기준을 정리합니다. 작은 예제로 동작을 확인한 다음 실제 상황에 맞게 적용합니다.

## 코드 예제

```sql
EXPLAIN SELECT * FROM posts WHERE slug = 'hello';
```

### 확인 방법

코드 복사 버튼과 목차 링크가 동작하는지 확인하세요. 정답을 외우기보다 선택의 이유를 기록하는 것이 중요합니다.

## 정리

변경 전후의 결과를 비교하고 필요한 만큼만 개선합니다.
