> 기능 확인을 위해 작성한 샘플 콘텐츠입니다. 기존 Velog 글이 아닙니다.

## 먼저 생각할 것

환경 설정부터 정적 파일 경로까지 배포 과정에서 점검할 사항입니다. 작은 예제로 동작을 확인한 다음 실제 상황에 맞게 적용합니다.

## 코드 예제

```bash
npm run check
npm run build
```

### 확인 방법

코드 복사 버튼과 목차 링크가 동작하는지 확인하세요. 정답을 외우기보다 선택의 이유를 기록하는 것이 중요합니다.

## 정리

변경 전후의 결과를 비교하고 필요한 만큼만 개선합니다.
